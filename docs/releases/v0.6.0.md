# MH Sidebar v0.6.0

Под блоками CPU, GPU и ОЗУ теперь видно, какие приложения сильнее всего нагружают устройство.

## Файлы

| Система | Архив |
| --- | --- |
| Windows x64 | `MH-Sidebar-v0.6.0-windows-x64.zip` |
| Linux x64 | `MH-Sidebar-v0.6.0-linux-x64.tar.gz` |
| macOS Apple Silicon | `MH-Sidebar-v0.6.0-macos-arm64.zip` |
| macOS Intel | `MH-Sidebar-v0.6.0-macos-x64.zip` |

У каждого архива есть файл `.sha256` для проверки загрузки. Инструкции по запуску и системным библиотекам находятся в `README.md`.

## Что изменилось

- Добавлен топ нагружающих приложений под блоками CPU, GPU и ОЗУ. Размер списка выбирается в настройках блока: выключен, 1, 3, 5 или 7; по умолчанию 3. Процессы с одинаковым именем складываются в одно приложение.
- CPU показывается как доля от всех логических потоков, ОЗУ — как занятая приложением память.
- Нагрузка приложений на GPU в Windows берётся из счётчиков WDDM для каждой видеокарты, в Linux и macOS — только для NVIDIA через NVML.
- Если список выключен во всех блоках, процессы не опрашиваются.

## Ограничения

Нагрузка приложений на GPU пока не проверена на реальном железе; на Linux и macOS она недоступна для видеокарт без NVML. Резервирование места на рабочем столе и датчики PawnIO остаются функциями Windows. На Linux точное положение панели рассчитано на X11; Wayland зависит от композитора. На macOS панель может перекрывать строку меню или Dock. Приложение для macOS не подписано и не нотариализовано Apple.
