# MH Sidebar v0.5.2

Первый выпуск с вариантами для Windows, Linux и macOS.

## Файлы

| Система | Архив |
| --- | --- |
| Windows x64 | `MH-Sidebar-v0.5.2-windows-x64.zip` |
| Linux x64 | `MH-Sidebar-v0.5.2-linux-x64.tar.gz` |
| macOS Apple Silicon | `MH-Sidebar-v0.5.2-macos-arm64.zip` |
| macOS Intel | `MH-Sidebar-v0.5.2-macos-x64.zip` |

У каждого архива есть файл `.sha256` для проверки загрузки. Инструкции по запуску и системным библиотекам находятся в `README.md`.

## Что изменилось

- Добавлены сбор показателей CPU, памяти, дисков и сети на Linux и macOS, а также NVIDIA GPU через NVML при наличии драйвера.
- Добавлены автозапуск, системный трей, горячие клавиши, импорт и экспорт файлов для Linux и macOS.
- Добавлены отдельные сборки для Intel и Apple Silicon Mac.

## Ограничения

Резервирование места на рабочем столе и датчики PawnIO остаются функциями Windows. На Linux точное положение панели рассчитано на X11; Wayland зависит от композитора. На macOS панель может перекрывать строку меню или Dock. Показатели GPU без NVML и мощность CPU на Linux/macOS могут быть недоступны. Приложение для macOS не подписано и не нотариализовано Apple. Сборки и тесты выполняются на каждой целевой ОС в GitHub Actions; ручные сценарии на Linux/macOS ещё не подтверждены.
