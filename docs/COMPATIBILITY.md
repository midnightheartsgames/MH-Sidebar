# Совместимость MH Sidebar v0.5.1

Дата проверки: 23 сентября 2026 года. Статус «проверено» относится только к указанной конфигурации. Сборка для Windows x64 и прохождение CI на Windows Server сами по себе не подтверждают работу на клиентских Windows 10 и 11.

| Сценарий | Конфигурация и проверка | Результат |
|---|---|---|
| Windows 11 | 25H2, сборка 26200.9457, x64; release EXE с отдельным конфигом и ограниченным временем работы | Проверено на одном ПК; код завершения 0. Номер сборки сопоставлен с [таблицей Microsoft](https://learn.microsoft.com/en-us/windows/release-health/windows11-release-information). |
| Windows 10 | Клиентская Windows 10 x64 | Не проверено: доступного отдельного ПК или VM с этой ОС нет. |

Реальное создание задачи и вход в Windows в изолированной тестовой среде не проверены; требуется проверка на пользовательском ПК. |

| Перезапуск Explorer | Завершение и повторный запуск оболочки с повторной регистрацией AppBar и значка трея | Не проверено: текущий сеанс не прерывался. Код отслеживает `TaskbarCreated`, но реальный перезапуск ещё нужно испытать. |

Замер ресурсов выполнен скриптом `tools/measure-resources.ps1` для release EXE с отдельным конфигом, видимой панелью, выключенными уведомлениями и резервированием рабочего стола. Система: Windows 11 25H2, 24 логических процессора, два монитора, реальные источники CPU/GPU/RAM/дисков/сети. После двух секунд прогрева выполнено 30 измерений с интервалом около секунды: 30,36 с, 0,78 с CPU, среднее 0,11% от общей мощности процессоров, пиковый рабочий набор 168,2 МиБ, пиковая приватная память 163,0 МиБ, максимум 460 дескрипторов и 19 потоков. Это наблюдение на одной машине, без статистики между запусками. Точные данные и stderr сохранены локально в `target/compatibility/resources.json`.

Для повторения проверки на другой машине сначала выполните `cargo run --locked --example compatibility_probe` и `cargo run --locked --example dock_probe`; последний тест кратковременно меняет рабочую область, поэтому нужен обычный интерактивный сеанс Explorer. Запустите `powershell -ExecutionPolicy Bypass -File tools/measure-resources.ps1` при отсутствии другого экземпляра MH Sidebar. Скрипт отслеживает и при необходимости останавливает только запущенный им процесс. Для выпуска выполните `powershell -ExecutionPolicy Bypass -File tools/build-release.ps1`; он создаёт отдельный каталог версии и ZIP, а `tools/verify-release.ps1` проверяет состав, SHA-256 каждого файла, версию EXE и архитектуру x64.

Релиз не подписан Authenticode. Отсутствие предупреждений SmartScreen и антивируса не гарантируется. В тестовом завершении приложение выводило `Error removing system tray icon` из библиотеки трея, при этом завершалось с кодом 0; показ уведомлений Windows и восстановление значка после реального перезапуска Explorer ещё не проверены.
