Read src/model.rs for Section, Reading, Block (Memory, Disks etc.) schemas. Sampler sample returns CPU, GPU(s), RAM, disk volumes and network adapters (no clock). Every reading key must be stable within its section/device and numeric value must be physical unit stated. RAM load (%), used/free/total (GiB). Disks load (% space used), used/total (GiB), read/write (MiB/s). Networks download/upload (MiB/s). Human-facing labels in Russian.
