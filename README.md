# MH Sidebar

Нативная боковая панель мониторинга для Windows 10/11 x64, написанная на Rust. Интерфейс в стиле MH Monitoring: Cuprum, тёмные карточки, бирюзовый акцент и живой предпросмотр.

## Запуск

Запустите `dist/MH-Sidebar.exe`. Установка и права администратора не нужны (кроме температуры и мощности CPU, см. ниже). При первом запуске откроются настройки: выберите монитор, сторону и ширину, затем нажмите **Готово**. По умолчанию панель выбирает второй монитор (или основной, если экран один).

- Левый клик по значку в трее — показать/скрыть панель.
- Правый клик — настройки, блокировка кликов, перезапуск датчиков, выход.
- **Ctrl+Alt+F11** — показать/скрыть; **Ctrl+Alt+F10** — пропускать клики; **Ctrl+Alt+F12** — настройки. Сочетания настраиваются.
- Кнопка `×` на панели скрывает её. Для завершения используйте **Выход** в трее.
- Колесо мыши прокручивает длинную панель. В режиме пропуска кликов управление доступно через трей/хоткеи.
- «Зарезервировать пространство» оставляет место для панели при разворачивании окон. Выключено по умолчанию.
- Автозапуск включается в общих настройках и использует только запись текущего пользователя. После переноса EXE выключите и снова включите автозапуск.

## Показатели

| Блок | Источник и показания |
|---|---|
| CPU | Загрузка, логические потоки, частота по данным ОС. Эта частота не является измерением мгновенного boost каждого ядра. |
| GPU NVIDIA | NVML из установленного драйвера: загрузка, температура, частоты, VRAM, мощность, вентилятор. |
| Другие GPU | WDDM/PDH: загрузка, VRAM и те датчики температуры/частот/вентилятора, которые предоставляет драйвер. |
| ОЗУ | Занято, доступно, всего и процент использования. |
| Диски | Объём томов, занятое место, чтение/запись через PDH. Процент — заполнение тома, не активность диска. |
| Сеть | Приём и передача отдельно для каждого интерфейса, включая виртуальные. В настройках можно выбрать нужные устройства. |

Память отображается в GiB, скорости — в MiB/s. Недоступные данные не заменяются нулями; причина видна в настройках устройства. Начальные скорости появляются после двух замеров. «Скрывать недоступные показатели» управляет видимостью таких строк на панели. Пороговые цвета в этой версии относятся к температуре GPU.

Температура и мощность CPU читаются через драйвер [PawnIO](https://pawnio.eu) (AMD Ryzen Zen 1–5 и Intel с цифровым датчиком). Драйвер ставится отдельно — кнопкой «Установить PawnIO» в настройках процессора (через `winget`) или с сайта; открыть его может только администратор, поэтому там же есть кнопка «Перезапустить от имени администратора». В exe встроены только подписанные модули PawnIO `AMDFamily17` и `IntelMSR` (см. `assets/pawnio/NOTICE.md`); с `PawnIOLib.dll` программа не линкуется. SMART/температура дисков и скорость модулей RAM в v0.1 не поддерживаются. Программа не включает WinRing0, LibreHardwareMonitor, PresentMon, службу или инъекции.

## Настройки

`%APPDATA%/MH Sidebar/settings.json`. Изменения в окне сначала видны в предпросмотре; **Применить** сохраняет их, **Отмена** отбрасывает. Порядок блоков меняется стрелками. Для каждого блока можно выбрать устройства, строки и показатель графика; история — 30–300 секунд.

Повреждённый JSON сохраняется в `settings.corrupted-<timestamp>.json`; более новая схема не перезаписывается. Запись файла выполняется через временный файл и атомарную замену. Приложение не отправляет телеметрию и не проверяет обновления по сети.

## Сборка и проверки

Требуются Rust stable с MSVC toolchain и Windows SDK / Visual Studio Build Tools (C++).

```powershell
cargo fmt --check
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo run --locked --example probe
cargo test --locked --lib -- --ignored --nocapture
cargo run --locked --example dock_probe
powershell -ExecutionPolicy Bypass -File tools/gui-smoke.ps1
powershell -ExecutionPolicy Bypass -File tools/build-release.ps1
```

`dock_probe` кратковременно резервирует место на втором экране и проверяет восстановление. Его нужно запускать в обычном сеансе рабочего стола: изолированная песочница без доступа к Explorer отклоняет AppBar.

`gui-smoke.ps1` требует предварительного `cargo build`; он использует отдельный конфиг в `target/gui-smoke`, проверяет Reset/Cancel, открытие настроек с панели, Reset/Apply и скрытие. На время кликов собственное окно выводится наверх, проверяется адресат клика и восстанавливается позиция курсора. Тест завершается остановкой только своего процесса.

Для отдельной тестовой конфигурации: `MH-Sidebar.exe --config "C:/path/settings.json" --settings`. `--smoke-test 15` завершает процесс через 15 секунд. В debug-сборке переменная `MH_SIDEBAR_CAPTURE_DIR` включает локальные снимки только собственных окон; в релизе этого кода нет.

## Проверенная конфигурация и ограничения

На машине разработки проверены Ryzen 9 5900X, RTX 5070 Ti, чтение NVML/WDDM, диски и сеть; реальный AppBar справа/слева, скрытие/возврат и освобождение рабочего стола. Геометрия с отрицательными координатами и дробным DPI покрыта тестами.

Физическое отключение мониторов, смена DPI во время работы и перезапуск Explorer требуют дополнительной ручной проверки на разных системах. Обработчики этих событий реализованы. Боковая панель задач Windows слева/справа может перекрывать нерезервирующую панель: в этом случае включите резервирование. Доступность GPU-показателей зависит от драйвера; GPU с одинаковыми названиями могут потребовать дополнительной проверки идентификации.

Релиз не подписан Authenticode; отсутствие предупреждений SmartScreen/антивируса не гарантируется. EXE не упаковывается UPX. Контрольная сумма находится в `dist/SHA256SUMS.txt`.
